# Helix Voice SDK for Go

## Installation

```sh
go get github.com/advai-x/helix-voice-go@v0.1.0
```

The Go package name is `helixvoice`.

See the [developer API documentation](https://docs.helixvoice.net/en/api/overview/) for authentication, capabilities and usage examples. The client is generated from the [OpenAPI contract](openapi.yaml).
